Support

Contact

Common Topics

Permissions: If voice, camera, contacts, calendar, health, or local network features fail, verify system permissions in iOS/macOS Settings.

Tool APIs: If external tools fail, re-check provider API keys and base URLs in Tools settings.

Backup/Restore: API keys are redacted in backups for security and must be re-entered after restore.

Performance: On-device model performance varies by device memory and thermal state.

Bug Reports

Please include:

1. App version and build number

2. Device model and OS version

3. Steps to reproduce

4. Screenshots/screen recordings (if possible)

Response Time

We aim to respond within 2-3 business days.
