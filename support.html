Support

Need help with Kukku? Contact us and include app version, device model, and issue steps.

Contact

Email: support@kukku.me

Common Topics

Permissions: If voice, camera, contacts, calendar, health, or local network features fail, verify system permissions in iOS Settings.

Tool APIs: If external tools fail, re-check provider API keys and base URLs in Tools settings.

Remote & external models: If Escalation mode or a connected remote / OpenAI-compatible endpoint returns errors, verify the API key, base URL, and model name, and confirm the device has network access.

Backup/Restore: API keys are redacted in backups for security and must be re-entered after restore.

Performance: On-device model performance varies by device memory and thermal state.

Bug Reports

Please include:

1. App version and build number

2. Device model and OS version

3. Steps to reproduce

4. Screenshots/screen recordings (if possible)

Response Time

We aim to respond within 2-3 business days.
